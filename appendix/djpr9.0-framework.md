# DJPR9.0 Framework

> **Decision Journey Process Reduction 9.0** — An applied Decision Intelligence methodology for evaluating search advertisement quality.

---

## Origin and Philosophy

DJPR9.0 is not a commercial entity, marketing agency, or software product. It is a **research-informed evaluative framework** developed for the systematic analysis of digital advertising ecosystems.

**Core Philosophy:**

```
Information → Insight → Decision → Value
```

This sequence is adapted from Decision Intelligence theory (Pratt & Malcolm, 2023). Each transition represents a potential failure point:
- **Information → Insight:** Data abundance does not automatically produce understanding
- **Insight → Decision:** Understanding does not automatically produce action
- **Decision → Value:** Action does not automatically produce outcomes

A structured framework is required to bridge each gap.

---

## The Four-Phase Cycle

Every evaluation task proceeds through the same four phases:

### Phase 1: Observe
**Goal:** Gather comprehensive information without premature judgment.

**Inputs:**
- Search query (literal terms + modifiers)
- Advertisement creative (headlines, descriptions, extensions)
- Landing page (content, structure, trust signals, technical performance)
- Competitive landscape (what other advertisers are serving)
- Apparent user intent (informational, commercial, transactional, navigational)

**Output:** Complete contextual dataset

**Discipline:** Resist scoring until all data is collected. A common error is forming a holistic impression before examining the landing page.

---

### Phase 2: Analyze
**Goal:** Apply structured analytical criteria to transform observation into evidence.

**Process:**
1. Classify query intent using Broder's (2002) taxonomy
2. Score each dimension of the rubric independently
3. Identify specific alignment and misalignment points
4. Document evidence for each score (quotation, screenshot reference, URL)

**Output:** Structured evidence matrix with dimension scores and justifications

**Discipline:** Score dimensions independently. Do not let a high score on one dimension inflate another.

---

### Phase 3: Interpret
**Goal:** Generate actionable insights from analyzed evidence.

**Process:**
1. Identify the root cause of quality deficiencies
2. Prioritize improvement opportunities by impact
3. Reduce uncertainty about optimal judgment
4. Distinguish between "poorly written" and "well-written for the wrong intent"

**Output:** Diagnostic narrative with prioritized recommendations

**Discipline:** Focus on the *specific constraint* — the one dimension that, if improved, would most increase overall quality.

---

### Phase 4: Recommend
**Goal:** Produce structured, calibratable decision output.

**Output Format:**
- Composite score (mean of dimensions)
- Per-dimension scores with written justifications
- Specific, actionable recommendation(s)
- Evidence citations sufficient for a second reviewer to reproduce or challenge

**Discipline:** Every recommendation must be concrete enough to implement. "Improve ad relevance" is insufficient; "Add 'small business' to the headline and reference the free tier in Description Line 1" is sufficient.

## Why "9.0"?

The version number reflects iterative refinement through nine major revisions:
1. Initial concept (information → decision mapping)
2. Integration of search intent theory
3. Addition of Quality Score component alignment
4. Development of the five-dimension rubric
5. Application to live advertisement evaluation
6. Extension to campaign architecture
7. Extension to keyword intent mapping
8. Integration of inter-rater reliability principles
9. Consolidation into a unified, documented framework

---

## Relationship to Decision Intelligence

Decision Intelligence (DI), as defined by Pratt and Malcolm (2023), is "a step-by-step method for integrating technology into decisions that bridge from actions to desired outcomes."

DJPR9.0 operationalizes DI principles in the advertising evaluation context:

| DI Principle | DJPR9.0 Application |
|-------------|---------------------|
| Make decision structure explicit | Five named dimensions with independent scores |
| Identify leverage points | Per-dimension diagnosis pinpoints exact improvement target |
| Reduce uncertainty before action | Evidence-based scoring replaces holistic impression |
| Human-in-the-loop advisory | Evaluator judges AI outputs; does not replace AI |
| Subject to retrospective improvement | Scored evaluations enable before/after comparison |

---

## Relationship to Inter-Rater Reliability

A rubric with named, independently scored dimensions is designed specifically to support **inter-rater reliability** — the degree to which independent evaluators reach the same verdict from the same evidence (Cohen, 1960).

**Design features that promote reliability:**
- Discrete dimension names (not holistic "quality")
- Numeric scale with consistent anchors (1–10)
- Written justifications for every score
- Evidence citations (query text, ad copy, landing page URL)

**Calibration application:** In a multi-rater setting, two evaluators applying DJPR9.0 to the same advertisement should produce dimension scores within ±1 point. Discrepancies indicate either (a) ambiguous evidence requiring guideline clarification, or (b) rater drift requiring re-calibration.
